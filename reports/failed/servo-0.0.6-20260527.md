## 9. 质量反馈

**失败阶段：** MSRV 预检（build-rpm precheck 阶段）

**根因：** 结构性约束冲突，无法通过修改 spec 解决。

| 字段 | 值 |
|------|-----|
| rust-toolchain.toml 声明 | `channel = 1.92.0` |
| 容器实际 rustc 版本 | `1.90.0` |
| 冲突类型 | `msrv_conflict` |

servo 的 `rust-toolchain.toml` 要求 rustc >= 1.92.0，而当前编译容器只提供 rustc 1.90.0，差距为两个小版本。该约束由上游显式声明，不应通过 `--ignore-rust-version` 等 flag 绕过，属于需要人工介入的结构性问题。

**可选解决方案：**

1. 升级编译容器的 Rust 工具链至 1.92.0 及以上，重新发起引入。
2. 改用与容器 rustc 1.90.0 兼容的 servo 历史版本（若存在）。
3. 在容器镜像中通过 `rustup override set 1.92.0` 安装指定版本工具链（需容器支持 rustup）。
